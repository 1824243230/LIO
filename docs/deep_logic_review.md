## 已修复的问题

| 问题与触发条件 | 修改后的行为 |
|---|---|
| 初始化后数帧建图一直使用固定初始位姿，不积分 IMU，但推进 last_obs_time；设备运动时地图和后续传播时间不一致 | 初始化建图也使用 Propagation_Undistort，按末端预测位姿插入去畸变点；仅完整扫描计入初始化帧数 |
| Predict 把 last_obs_time 当积分起点，观测时间领先真实状态时会跳过未积分区间 | 积分从真实 IMU 左端点开始，观测时间记录不再决定传播区间 |
| 扫描末端 IMU 未覆盖或某一步预测失败，仍配准/入图/发布该扫描 | Propagation_Undistort 返回成功标记；末端必须确实被传播覆盖，失败则不进入观测、地图和输出；有效传播前缀保留供下一扫描继续 |
| 有限但极大的 IMU 输入使运算溢出，原逻辑先更新时间并原地修改状态/协方差 | 在局部计算并检查所有候选量，成功后统一提交；主预测和高频预测均拒绝非有限运算结果 |
| 上一轮只修了协方差查询，普通 deskewPoint 的 NaN 时间仍可能二分查找到 end() 后越界 | 普通去畸变入口也先检查点坐标和时间；整帧去畸变结果非有限时不进入后续流程 |
| 实际 Livox 回调按 point_num 索引，却未检查 points 数组长度；先前被测试的备用转换函数不覆盖此路径 | 实际回调使用共享 convertLivoxScan，拒绝声明长度不符和无效步长；测试直接使用该生产转换函数 |
| 迟到的 IMU 会清空有效队列，并把时间退回；重复扫描末端也可能重新处理 | 迟到/重复 IMU 拒收且不改变队列；同步只接受递增扫描末端，保留右侧 IMU 给下一帧 |
| 缺少末端 IMU 时同步器与缓存 MeasureGroup 状态交织 | 同步逻辑独立为可测试函数，右侧样本到齐之前不消耗左侧样本，也不修改输出测量组 |
| 地图保存使用 shell 删除整个 PCD 目录、分片写失败后照样清缓存；合并遍历旧文件且忽略读取失败 | 每实例创建 PCD/run-* 目录，仅记录成功写入的分片；成功后才清缓存/推进索引，失败可重试；只合并本次清单，缺任一分片不覆盖最终地图 |
| 最终地图写入失败可能覆盖原文件；非分片路径无视 if_filter=false | 同目录临时文件写完并成功改名后提交；两种保存路径遵守同样的过滤开关 |
| 重定位忽略 map_init 失败，打印成功后仍对空地图配准；加载标记/更新倒计时是函数静态变量 | 读取失败或清除非有限点后为空则初始化失败并由节点报错退出；标记和倒计时属于各估计器实例 |

地图保存代码移到 `src/lio/map_io.cpp`，减少核心观测文件中无关逻辑。
CMake 的源文件搜索增加 CONFIGURE_DEPENDS，新增源文件会触发重新配置，避免新实现未链接。

## 时间与失败处理的约定

- “推进了观测时间”不等价于“积分到了这个时间”。名义状态、测量端点、去畸变末端必须一致。
- 不完整扫描不发布新的扫描点云或里程计；它之前成功积分的状态保留，下一个可用扫描可以继续。
- 对短时间乱序采用丢包策略；整段 rosbag 时间回绕必须重启节点，不能只清 IMU 队列却沿用旧状态和地图。
- 本轮没有新增长时间 IMU 中断检测或自动重初始化阈值。若较远的后续样本仍有效，传播仍按现有区间平均测量模型积分；长间断运动真实性不受这些测试保证。
- 扫描头部早于当前可用状态时仍采用已有边界夹取，未加入反向传播或跨扫描轨迹平滑。
- 建图初始化现在允许 IMU 预测运动；最初估计偏置和重力仍依赖近似静止启动。初始化期间不做激光校正，不能据此声称解决任意动态启动。

## 验证范围

新增 `deep_logic`：

- 基础/smooth 两条路径在四帧初始化中的时间及恒速位移正确；同一世界点去畸变后不因运动被叠错。
- 末端 IMU 缺失时无观测、地图写入或输出；下一扫描继续积分，无时间丢失。
- 有限输入溢出后时间、状态、协方差、转移矩阵不变，主/高频预测均可用合法样本继续。
- 迟到/重复 IMU、借用右侧样本、精确末端、重复扫描、等待及恢复同步。
- 实际 Livox 转换中的长度不符、乱序点时间、非法步长，以及普通去畸变 NaN 查询。

新增 `map_io`：在独立 `/tmp` 目录实写实读 PCD，检查含空格/分号的路径、旧文件保留、
多实例分片隔离、缺分片不覆盖完整地图、重命名失败保留缓存并重试、目录创建失败保留点云，以及关闭过滤时不丢同体素点。
测试结束只删除该测试自己创建的临时目录。

没有运行数据集或 ROS master 下的重定位启动测试，没有逐行审计第三方库。
