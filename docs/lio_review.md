# LIO 与退化设计审查（2026-09-30）

## 已修复的问题

| 问题 | 影响 | 实现 |
|---|---|---|
| `A n = -1` 平面拟合固定常数项 | 不能表示穿过世界原点的平面，共线邻点可能产生虚假法向 | 中心化协方差最小特征向量拟合法向；要求两个方向有支撑，保留 0.1 m 邻点残差门限 |
| IMU 同步只取扫描结束前的数据 | 状态可能停在上一条 IMU 时刻，扫描末尾缺少运动补偿 | 借用但不弹出结束后的第一条 IMU；插值到扫描结束，保存该端点供下一帧继续积分 |
| 去畸变搜索可能读取 `end()`，累计未成功传播的重复状态 | 边界越界、零时间间隔、运动补偿异常 | 只保存成功且时间递增的传播状态；显式处理首尾边界；二分查找时间区间 |
| IESKF 显式求逆，普通 plane 更新缺少数值回退 | 弱约束下放大数值问题，后续迭代失败可能留下部分修正 | 双精度 LLT 求解；失败恢复整帧滤波器快照；检查后验有限性和正定性 |
| 观测失败后仍向地图插点 | 将预测漂移或数值异常写入地图，反馈到后续配准 | 保留 IMU 先验，跳过在线地图和保存地图的插入 |
| Velodyne 过滤后空点云仍调用 `back()` | 空帧崩溃 | 丢弃空帧和非有限点，按有效点时间最大值确定扫描结束 |
| `stateProcess` 与 `Observe` 重复增加帧计数 | 一帧计两次 | 仅正常处理入口增加一次，纯 plane 重放不增加 |
| 无可查询 bump 表面仍进行精细采样准备 | 额外 KNN、fine/coarse 采样与纯 plane 重放均无收益 | 在测量增强模式下预检查当前完整点云；无支持表面时保留原采样，退化分析移至正常 Observe |

`gate_01` 首帧点时间约为 [-0.09951, 0.000643] 秒，负偏移合法。输入归一化使用 `start_new = stamp + min(offset)` 和 `offset_new = offset - min(offset)`，保留每一点的绝对时间。测试覆盖此约定，不能将负偏移当坏点删除。本轮短段回放曾发现新增过滤误删负偏移的问题，已修复后重新验证。

## 退化策略的边界

- 保留传播先验，允许测量矩阵低秩；不能因为弱方向缺少激光约束而直接丢弃整帧有效约束。
- Bump 仍仅在可靠历史表面、有效梯度和弱方向贡献等条件满足时参与更新。纯平面或长走廊轴向运动的不可观性不能凭空消除。
- 新增 `degeneracy_M2DGR.launch` 支持明确的消融开关，默认 `enable=false`，增强实验必须显式设置 `enable:=true`。该入口设置 `bump_degenerate_variance_factor=1`，避免仅因退化程度增加就假设 bump 噪声更小；质量相关方差与 Huber 权重仍保留。既有 MID360 实验入口保持原参数。
- 未将 Jacobian 人为投影到弱子空间，也未重写 IMU 噪声单位、传播噪声模型和退化阈值。这些约定需要独立标定，不能用试调 ATE 代替。

采样预检查仅基于传播先验位姿，属于保守的采样决策；后续 IESKF 迭代仍可查询并接受原采样上的有效 bump，地图准备也继续运行。单独开启 informed sampling 的消融实验保留既有行为。预检查省略提前分析时，首次 Observe 必须推进一次退化迟滞，不能因为全局 sampling 开关仍开启而漏掉状态更新。

## 验证方法

```bash
source /opt/ros/noetic/setup.bash
source /home/hyh/rong_ws/Super-LIO/devel/setup.bash
catkin_make -C /home/hyh/rong_ws/Super-LIO -j2 -l2
cd /home/hyh/rong_ws/Super-LIO/build
ctest --output-on-failure -R '^(geometry_|lio_numerics)'
```

六项测试包含原有 geometry 检测、地图、采样、滤波与回退回归，以及新增的原点平面、共线/非有限邻点、时间边界、扫描末端 IMU 插值、下一帧剩余积分、低秩测量保留先验、后续迭代失败后的整帧恢复、空扫描和有符号点时间测试。

真实回放使用独立 ROS master，关闭可视化地图发布，原速播放 `/velodyne_points` 与 `/handsfree/imu`，使用消息时间戳保存 TUM。ATE 使用 `evo_ape tum -r trans_part --align --t_max_diff 0.02`，不拟合尺度。模块耗时不代表开启 RViz 后的整机端到端延迟。

## gate_01 完整回放结果

| 版本 | 匹配位姿数 | ATE RMSE / m | 最大位置误差 / m | 四模块平均耗时合计 / ms |
|---|---:|---:|---:|---:|
| 保存的修复前二进制 | 1713 | 0.155824 | 0.409798 | 5.22 |
| 基础修复版，geometry 关闭 | 1714 | 0.151596 | 0.363340 | 5.40 |
| 基础修复 + geometry，采样优化前 | 1714 | 0.151596 | 0.363340 | 34.62 |
| 基础修复 + geometry，采样优化后 | 1714 | 0.151596 | 0.363340 | 27.00 |

本次回放基础修复后 RMSE 下降约 2.7%，最大误差下降约 11.3%；基础计算耗时略增约 3.4%，不能声称整体提速。四模块为 Undistort、DownSample、Observe、UpdateMap，数字取各模块平均值之和，不含 ROS 输入转换、输出和可视化，也不是峰值时延。每个版本只完整回放一次，时间结果受机器负载影响，不是多次重复实验的统计结论。

增强版两个实验均为 1714 帧判定 DEGENERATE，0 帧接受 bump，全部回退 plane。这个结果说明当前特征值尺度/阈值和高度图支持条件尚未在 gate 上证明能提供有效额外约束，不能把“检测到退化”解释为“已修复退化”。采样优化后位置轨迹与基础修复版一致，无支持表面时的耗时合计下降约 22%，但维护附加地图仍有成本。当前推荐默认关闭增强，保留显式实验入口。

所有输出消息均参与时间匹配；首帧时间和数量有一帧差异，来自初始化/同步路径变化，不是手工删点。上述为整段全局 SE(3) 对齐误差，不是起点对齐后的终点漂移。未进行逐项算法消融，不能将收益单独归因于某一项修复。

## 尚需验证的设计风险

1. Bump 替换 plane 的净信息变化不保证所有方向都增加；弱方向打分不等价于全局可观性改善。
2. 历史地图来自同一估计器，重复观测相关性和地图误差未完全计入方差；MID 和梯度不是经过标定的噪声模型。
3. 初始 IMU 均值估计仍依赖启动阶段近似静止。长时间完全退化时，纯 LIO 缺少外部速度或位置约束，漂移仍不可避免。
4. 真值和 IMU 的参考点、杆臂与姿态坐标系未完全核实；这里报告对齐的位置 ATE，不能直接解释姿态 RPE。
5. gate 序列与合成退化测试不能替代 Corridor/tunnel 的实测验证，也不能证明所有传感器配置均提升精度。
