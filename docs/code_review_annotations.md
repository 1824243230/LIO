# 代码检查与中文注释补充

本轮检查范围：LIO 传播与观测更新、退化检测与谱加权、采样与回退、点云转换、关键 ROS 参数读取，以及地图缓存的非正保存间隔分支。采用源代码审查、编译和小型数值/边界测试；未运行数据集，也不将这些检查解释为实际定位性能验证。未逐行审计第三方依赖。

## 发现并修复的问题

| 位置 | 问题 | 修复 |
|---|---|---|
| ROSWrapper 参数读取 | 外参数组缺失/长度不足时直接索引，可能越界；未检查非有限值 | 要求 lidar_imu 为 12 项、odom_robo 为 6 项且全部有限，失败时由节点报告配置错误并退出 |
| ROSWrapper 参数读取 | blind/maxrange、hash_capacity 读取失败后使用未初始化局部变量 | 必填读取检查，并检查距离范围与容量有效性 |
| 发布频率参数 | pub_step 为 0 会导致取模除零 | 缺失默认 1，非正值限制为 1 |
| caceData / saveMap | save_interval=0 时每帧清空缓存写分片，但退出时走非分片路径，无法正确保存最终地图 | 两个入口统一使用非正间隔表示内存累积、退出保存 |
| 备用 livox2pcl | 空包构造 size-1 长度、声明点数与数组长度不一致可能越界 | 提前拒绝空包/长度不一致；支持空输出指针 |
| 备用 livox2pcl | 并行读取前一元素时其可能仍在写入；vector<bool> 不同下标也可能共享存储字 | 从不可变原消息顺序读取，去除共享并行标记和临时点云；保留从第 1 点开始的原接口约定 |
| 建图/重定位初始化 | 加速度均值为零时归一化重力产生非法数值 | 均值及重力常量无效时不提交初始化，继续等待 |

备用 livox2pcl 当前无仓内调用点；修复不能描述为当前 Livox 实际回调中的故障。实际回调采用独立的带时间偏移转换路径。

本轮没有发现需要修改谱权重公式的问题：旋转长度缩放、信息矩阵与右端项的同步权重、最终曲面替换后再分析、平面回退继续保护等逻辑与设计一致。这不等价于全项目无错误或算法统计一致性证明。

## SE(3)-LIO 适配后追加审查

本次保留工作区已有修改，重点检查新运动补偿模块与原传播、初始化、采样的衔接。

| 已确认问题 | 后果 | 本次修改 |
|---|---|---|
| 体素键按 15 bit 拼接，且用固定偏移试图消除负坐标 | 大坐标跨轴覆盖、负数转无符号后多个不同体素被当作同一个键，错误删点 | 完整有符号三维坐标作键，哈希碰撞由完整键相等比较解决；整型转换前检查有限性与范围，拒绝非法分辨率 |
| `SetX` 只设置状态与 IMU 时间，未设置实际 IMU | 首次积分把默认零测量或另一时刻旧测量当作左端点 | 初始化同时提供同时间的真实 IMU；仅改变状态时刻时使不匹配的测量缓存失效 |
| 激光校正只重置高频预测状态/时间，未重置其 IMU 测量 | 后续梯形积分混用扫描末端状态与校正前未来时刻的测量 | 状态、时间、插值后的扫描末端 IMU 一起重置；无匹配测量则等待建立锚点 |
| 高频 `Predict` 接受重复时间和非有限测量 | 重复发布、非有限状态污染 | 拒绝非有限输入和 dt≤0 |
| 基础传播的位置二次项缺少对应位置 Jacobian 和加速度噪声 | 名义位置与协方差模型不一致；位置方差及位置-速度相关性漏计 | 补全对姿态、加速度偏置、重力的导数及位置噪声项；沿用既有离散噪声单位 |
| 初始化用函数静态均值，且重复统计借用的右侧 IMU | 多实例共享统计，扫描边界样本重复加权 | 改为实例内统计，仅接受时间严格递增的有效测量；重定位重置时清空统计 |
| 点协方差插值未拒绝 NaN 查询时间 | 二分查找可能得到 end() 后访问越界；非法终点点坐标也可能返回零方差 | 二分查找及终点分支前检查有限性，返回无效协方差交由观测路径拒绝 |

新增中文注释解释体素键为何不能直接拼接、初始化时间锚点、两条预测轨迹的端点一致性、
基础传播位置导数、联合相对协方差的反向递推和共享误差抵消、小角度级数及插值近似。

新增 `logic_review` 回归测试以可复现输入覆盖以上缺陷；保留原有传播、几何、谱权重、运动补偿与回退测试。
