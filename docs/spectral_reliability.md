# 退化环境下的方向可靠性加权（2026-09-30）

本轮交付为理论设计、代码实现与数值性质检查，没有运行任何数据集，也没有估计 ATE、RPE 或性能提升比例。本文不沿用此前 `lio_review.md` 的回放结果作为新算法证据。

## 问题与本项目的改进

已有实现能检测弱方向，并以历史高度图的微小曲面约束替换部分平面约束。但是，纯平面或缺少可靠历史高度图时，补偿项不可用；含法向误差的弱方向观测仍进入滤波器。仅检测退化不能控制这些观测的影响。

本次增加最终观测系统上的连续谱权重：先完成平面与 bump 的互斥替换，再根据实际剩余约束分配方向可靠性。已有检测仍使用平面系统，负责曲面候选与迟滞；新权重使用最终系统，避免把已由曲面改善的方向一直当作弱方向。无 bump 的回退路径同样加权。

按方向处理退化已有研究基础：[Zhang、Kaess、Singh，ICRA 2016](https://publications.ri.cmu.edu/on-degeneracy-of-optimization-based-state-estimation-problems)。本项目的改进是连续权重、曲面补偿后的重新分析，以及在现有 IESKF 中同步改变信息矩阵和残差项。不能仅据此宣称论文级首创，仍需进一步文献比较与后续实测。

## 推导

点到面或曲面残差线性化为 `r + J δx`，观测信息与右端项为：

```
A = Σ Jᵀ R⁻¹ J
b = -Σ Jᵀ R⁻¹ r
```

位姿增量顺序为机体右扰动旋转、世界坐标平移。令 `z = [ℓ δθ, δp]`，`δx = S z`，`S = diag(1/ℓ,1/ℓ,1/ℓ,1,1,1)`，得到：

```
Az = Sᵀ A S = U diag(λi) Uᵀ
bz = Sᵀ b
ρi = max(λi, 0) / λmax
 ti = clamp(ρi / τ, 0, 1)
 gi = ti² (3 - 2 ti)
A'z = U diag(gi λi) Uᵀ
b'z = U diag(gi) Uᵀ bz
A' = S⁻ᵀ A'z S⁻¹
b' = S⁻ᵀ b'z
```

`τ = spectral_full_ratio`，默认 0.02；`ℓ = rotation_length_scale`，默认 1 m。它们是需要后续标定的设计参数。数值相对特征值不超过 `1e-12` 时视为零模式，权重为零。特征分解失败、非有限输入、全零信息或显著负特征值会拒绝该观测；ESKF 恢复本帧传播先验并跳过地图插入。只允许舍入量级的负谱，截为零。

这相当于在缩放坐标下对白化测量的左奇异模式应用相同的可靠性权重。不是仅缩小求解后的位姿增量：仅改增量会让实际修正与后验置信度不匹配。

在输入为半正定、固定线性化和固定权重的条件下：

- `0 ≤ gi ≤ 1`，因此 `0 ≼ A' ≼ A`，不会给激光系统添加虚构的信息。
- 零空间不产生激光信息和残差驱动力；强模式达到阈值后完整保留，过渡函数在两端一阶连续。
- 18 维 IMU 先验不做谱投影，速度、偏置、重力与位姿之间的交叉协方差仍参与更新。弱方向可能经先验相关性间接修正，不能理解为强制冻结某个坐标轴。
- 对相同先验 `P`，`(P⁻¹ + embed(A'))⁻¹ ≽ (P⁻¹ + embed(A))⁻¹`。即这个线性化模型中的后验不会比未降权时更加自信；该关系不等价于非线性轨迹误差一定下降。
- 额外计算仅涉及一个 6×6 对称特征分解及常数大小矩阵运算，每次观测迭代执行一次；没有增加逐点 KNN 查询。没有测量本次改动的实际耗时。

## 开关与诊断

所有既有默认配置保持新功能关闭。`enable_spectral_reliability=true` 需同时 `enable_degeneracy=true`，否则配置校验拒绝并关闭扩展。

`degeneracy_M2DGR.launch` 增加独立 `spectral` 参数：

| enable | spectral | 行为 |
|---|---|---|
| false | false | 基础修复版 |
| true | false | 原有检测、采样与曲面补偿 |
| false | true | 检测与谱可靠性，无高度图维护开销 |
| true | true | 曲面补偿后再做谱可靠性加权 |

这是配置说明，本轮未启动节点或回放数据。其他传感器可通过 `/lio/geometry` 参数使用相同模块。

新增 ROS 指标和 CSV 列：`spectral_valid`、`spectral_attenuated_modes`、`spectral_min_gain`。这些指标记录最后一次观测构建，不能替代整帧更新成功或轨迹精度指标；关闭模块时 valid 为 false、其余为默认值。原有 degeneracy_ratio 仍是平面信息的谱比，不是处理后信息的谱比。

## 代码检查范围与边界

新增独立数学性质测试，以及滤波和实际 Observe 回退路径的回归检查：强模式不变、零空间无伪信息、PSD 和信息非增加、旋转/平移坐标缩放一致、Hessian 与右端项一致、非法输入原子拒绝、弱方向修正与后验协方差同步改变、无曲面时仍执行谱保护。这些小型构造检查验证实现与公式一致，不属于数据集性能实验。

需要明确的局限：

1. 几何弱不一定等于测量不可靠。若弱约束本来正确，降权会丢失有效信息、增加漂移；谱比不能替代噪声标定。
2. 谱比只刻画相对各向异性。整体信息很弱但各向同性、外点主导强模式等情况，需要额外的质量模型，本次未声称解决。
3. 权重取决于当前线性化，采用冻结权重的迭代近似，没有对权重求导；上述 PSD 与协方差结论是局部代数性质，不是全局收敛或统计一致性证明。
4. 高度图误差与当前状态相关、重复观测相关性、IMU 偏置漂移仍存在。完全不可观测方向不能靠加权恢复，长期退化仍可能需要外部信息。
5. 不同阈值和旋转长度会改变结果，默认值没有经过退化数据集验证。本轮不设计或执行数据集实验。
